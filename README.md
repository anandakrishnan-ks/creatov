# CREATOV Engineering Consultancy

A modern, high-performance web application built for CREATOV Engineering Consultancy Pvt. Ltd. This platform showcases the company's architectural design, structural engineering, and construction consultancy services in Kerala.

## Tech Stack Overview

This project is built using modern web development technologies to ensure speed, accessibility, and a great developer experience:

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) for blazing fast development and optimized production builds.
- **Routing**: [TanStack Router](https://tanstack.com/router/latest) for type-safe client-side routing.
- **State Management**: [TanStack Query](https://tanstack.com/query/latest) for powerful asynchronous state management and data fetching.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) for utility-first, responsive styling.
- **UI Components**: 
  - Custom UI components built on top of [Radix UI](https://www.radix-ui.com/) primitives for full accessibility.
  - Icons provided by [Lucide React](https://lucide.dev/).
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/) coupled with [Zod](https://zod.dev/) for robust schema validation.
- **Language**: [TypeScript](https://www.typescriptlang.org/) for static type checking and enhanced developer tooling.

## Development Setup

To run this project locally, you will need Node.js and npm installed.

1. **Clone the repository**:
   ```sh
   git clone https://github.com/anandakrishnan-ks/creatov.git
   cd creatov
   ```

2. **Install dependencies**:
   ```sh
   npm install
   ```

3. **Start the development server**:
   ```sh
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

## Build for Production

To create a production-optimized build:

```sh
npm run build
```

To preview the production build locally:

```sh
npm run preview
```
